One snapshot. The whole server.

Each backup is a complete copy of how your server is built and what has been said in it.

Roles

Names, colours, icons, hierarchy order and every permission flag.

Channels

Text, voice, forum and announcement channels with categories, topics and slowmode.

Permissions

Per-channel and per-category overwrites for every role and member.

Messages

Content, authors, attachments, embeds, replies and pinned messages, up to the limit you set.

Custom emojis and stickers, re-uploaded with the same names.

Server settings

Name, icon, banner, verification level, system channels, bans and webhooks.

Four commands run it all.

Only members with Administrator can use them. Every action is written to your log channel.

CommandWhat it does
/backup createSaves the server now
/backup listShows saved backups
/backup restoreRebuilds from a backup
/backup scheduleSets automatic backups

Return to any saved moment.

Restoring works on the same server or on a brand-new one, so a deleted server is not the end.

  1. Pick a backup

    Run /backup list and copy the ID of the moment you want back.

  2. Choose what returns

    Restore everything, or only roles, channels or messages.

  3. Confirm

    The bot shows exactly what will change. Nothing happens until you approve it.

Questions

Where are backups stored?

Encrypted at rest, under your server ID. Only your administrators can list or restore them.

Does the bot need Administrator?

It needs permission to manage roles and channels to restore them. Backing up only needs read access.

Can I delete my data?

Yes. Run /backup delete for one backup, or remove the bot to erase all of them.

Your server deserves a second life.

Add the bot, run one command, and your server has a restore point.
